#

人物画像にアイシャドウ、アイライン、口紅、サングラスを着用できます。
Webcamera にも対応していますが、ソースコードの調整が必要です。
デフォルトでは指定した画像に対して適用するようにしています。

python, cv2、mediapipe、numpy などのインストールが必要です。

実行方法
python face_mesh.py
